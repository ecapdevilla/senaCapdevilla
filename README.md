# SENA 2027 – Banco de Instructores (Hoja de vida y plan de acción)

Repositorio privado de trabajo para organizar la postulación de **Estiben Rafael Capdevila Pacheco** al **Banco de Instructores SENA 2027**.

## Contenido
- `docs/Plan_Accion_Banco_Instructores_SENA_2027.md`: plan de acción completo y cronograma.
- `docs/HV_ESTIBEN_CAPDEVILLA_SENA_2027.md`: hoja de vida prellenada con datos y soportes.
- `docs/HV_SENA_2027_plantilla.md`: plantilla genérica.

## Cómo usar en el computador de casa
1. Copia/pega los soportes faltantes en `soportes/` (o en Descargas).
2. Actualiza `docs/HV_ESTIBEN_CAPDEVILLA_SENA_2027.md` con los nombres de archivo.
3. Cuando el portal cargue, registra la HV y adjunta los soportes (PDF/JPG/PNG, máx. 10 MB).
4. Haz commit y push a tu repositorio privado de GitHub.

## Subir a GitHub (privado)
```bash
git remote add origin https://github.com/TU_USUARIO/sena-2027-hv.git
git branch -M main
git push -u origin main
```
